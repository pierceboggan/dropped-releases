# Dropped desktop downloads

This repository distributes reviewed installers for Dropped, a local-first cycling training app. App source and development history are maintained separately.

The first public release is planned for macOS on Apple Silicon and Intel, plus Linux x64. macOS installers require Developer ID signing and notarization before publication. Windows downloads are deferred.

Each published release includes a manifest and SHA-256 checksums. Choose the installer matching your operating system and processor; GitHub's generated source archives are not installers.

The first release is being prepared. Read the release notes for signing status, hardware support and installation guidance before installing. Bluetooth and optional ERG control require supported macOS or Windows setups; physical hardware validation remains incomplete. Linux Bluetooth is currently unsupported.

Only installers, public release notes and distribution documentation belong here.
